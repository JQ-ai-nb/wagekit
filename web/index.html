为什么这个库存在

钱是整数分，浮点从不出现在任何中间量；累计预扣预缴是跨月状态机，单月函数必然算错跳档； 年终奖单独计税在每档边界都有一个「多发一分、少拿千元」的悬崖。 WageKit 用 Python Decimal 独立实现作为逐字段对照的 oracle（随机 3,000 组 + 全部跳档点 ±1 分穷举），两个实现谁错了都会被发现。
