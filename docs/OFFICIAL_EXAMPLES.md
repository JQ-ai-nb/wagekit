# 官方公开示例对照

本项目内置规则限定2026年中国大陆居民个人的普通累计预扣与居民年度计算。
以下是税务机关公开的历史示例，按2026年仍相同的税率表、基本减除常量及现行奖金政策
复算，用于检查公式和程序实现；不能据此推断本软件支持历史年份或自动判断个人扣除资格。

| 用例 | 来源与适配 | 程序应得到的结果 |
| --- | --- | --- |
| 单月工资累计预扣 | [广东税务2019年示例](https://guangdong.chinatax.gov.cn/gdsw/czsw_dmtxc/2019-08/21/content_69a9e51091954bbaa3a0328860678485.shtml)：工资10000元、社保1500元、专项附加1000元；该金额的2026年实际资格由调用方确认 | 第一期75元 |
| 奖金两种计税 | [税务总局2020年问答](https://www.chinatax.gov.cn/chinatax/n810219/n810744/n3752930/c101627/c5147704/5147704/files/936a47c7c6ee4048947fc8db145cd86b.pdf)第18–19页：全年工资120000元、专项附加12000元、奖金48000元；工资与扣除均摊12期 | 单独奖金4590元、工资综合所得2280元；全部并入7080元 |
| 年度综合所得 | 同一问答第12–14页：工资144000元、折算后其他收入34800元、扣除62400元、已预缴合计7608元；工资与扣除按12期均摊，示例工资预扣648元、其他预扣6960元 | 年应纳3120元、估算退税4488元 |

奖金并入示例为了演示补税计算，假设此前已按单独方式合计预缴6870元；
这一预缴假设由本项目添加，不能作为原文件对实际缴款的认定。
奖金政策延续至2027年底，见[2023年第30号公告](https://jiangsu.chinatax.gov.cn/art/2023/8/28/art_8349_432405.html)。

输入、期望结果、来源链接和适配说明见 `examples/official-reference-cases.json`。
运行 `node scripts/build.mjs` 后执行 `node --test tests/official.test.mjs`。
